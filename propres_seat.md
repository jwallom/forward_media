# Sunday ProPresenter Seat Outline

This is designed to be a checklist/guide to running the presentation computer, TV's, projector and
lights for Sunday services.

## Pre-Service

### 7:00am: Setup

- [ ] Ensure media computer is on. It is a good idea to reboot it at this time too.
- [ ] While the computer is rebooting, it is a good idea to make sure the blue stage lights are on.
- [ ] Make sure the power strip is turned on that runs the rail lights in the booth
- [ ] Turn on the center and side lights for practice.
- [ ] Make sure the volume is all the way up on the computer

### During practice

The songs should already be loaded in the correct section in ProPres.

- [ ] Pay attention to the practice and make sure the song order is correct. Adjust the arrangement as
      needed.
- [ ] Ensure the lyrics are formatted properly.
  - 1920 x 1080 screen size
  - No more than 4 lines per slide
  - Font size > 80pt < 100pt
  - Try to ensure line breaks make sense with song
  - Use groups! (Verse 1, Chorus, Verse 2, Bridge, etc)
  - The first slide should be in the intro group with no background, a clear all queue, and Worship
    screen set.

### Between Practice and Service

- [ ] Setup teaching slides from Dropbox
- [ ] Verify the bible function is set to display appropriately
- [ ] Get any clarification needed from Worship team
- [ ] **15m before Service**:
  - Turn off center lights
  - Ensure the pre-service slide deck has started
  - Set stage Display to pre-service(main output with clocks)
  - Start Spotify pre-service playlist
  - Verify that the countdown has started(automated)
- [ ] **5m before Service**: Turn off side lights

### 9:00 and 11:00am: Service Start

- [ ] Pay attention to worship leader and be prepared to turn on spot lights when they give a thumbs up.
- [ ] Click the intro slide on the first song to clear the pre-service loop and setup Worship stage
      display.
- [ ] Follow Worship with lyrics.
- [ ] As worship is ending, get ready for MC + Announcements
  - _Ensure Spotify is paused/stopped_ - [F8 pauses media]

### ~9:30 and 11:30: MC and Announcements

- [ ] Be prepared for testimonies. [ctr+b] launches the bible, try to pull up any verses used. Default
      to NKJV.
- [ ] **IMPORTANT**: Turn on side lights when band is dismissed.
- [ ] Wait for the MC to say roll the announcements, look to the sound person to ensure they are ready.
      When they give the thumbs up, start the video!
- [ ] As soon as they start, _turn off the spot lights._
- [ ] When announcements end, _turn on the spot lights quickly followed by the side lights._

### Teaching

- [ ] Pay attention and be ready to assist Clint or any other teacher.
- [ ] Verify the stage display is set to teaching for Clint
- [ ] In general Clint drives this section, but sometimes asks for a slide or follow along.

### 10:28am and 12:28pm: End of service

- [ ] When Clint plays the pads start Spotify end of service playlist
- [ ] Start end service slide loop
